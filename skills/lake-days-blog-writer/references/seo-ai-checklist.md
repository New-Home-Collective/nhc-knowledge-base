# SEO + AI Optimization Checklist

Reference for every blog post produced by the lake-days-blog-writer skill (LakeDaysCabinStays.com only).

---

## Part 1: Traditional On-Page SEO

### Keyword Placement
- [ ] Primary keyword in H1 (title tag)
- [ ] Primary keyword in first 100 words of body text
- [ ] Primary keyword in meta description
- [ ] Primary keyword in at least one H2
- [ ] Primary keyword used naturally 3-6x total (no keyword stuffing)
- [ ] Secondary keywords distributed naturally (1-2x each)
- [ ] LSI/semantic keywords present throughout (Google expects topic completeness)

### Title & Meta
- [ ] Title (H1): 50-60 characters, keyword near front, compelling
- [ ] Meta description: 150-160 characters, keyword included, ends with soft CTA
- [ ] URL slug: short, keyword-forward, no dates, hyphens only (e.g., /neighborhoods-lexington-ky)

### Content Structure
- [ ] H2 and H3 tags used correctly (H2 = major sections, H3 = subsections)
- [ ] At least one H2 contains primary or secondary keyword
- [ ] Table of contents included for posts 1,000+ words
- [ ] FAQ section included (H2 level, 3-5 Q&As)
- [ ] Short paragraphs (2-4 sentences)
- [ ] Bullet lists and numbered lists used where natural
- [ ] Bold on key terms at first use
- [ ] Word count: 1,000-2,000 words (800+ minimum)

### Links
- [ ] 2-3 internal links to relevant site pages
- [ ] 1-2 external links to authoritative sources (opens new tab)
- [ ] No links to competitor sites
- [ ] Link anchor text is descriptive (not "click here")

### Images
- [ ] Every image has an ALT tag with primary or secondary keyword
- [ ] File names are descriptive (lexington-ky-neighborhoods.jpg not IMG_1234.jpg)
- [ ] Images compressed for page speed (note in output)

### Schema Markup (flag for developer)
- [ ] Article schema on all blog posts
- [ ] FAQPage schema on FAQ sections
- [ ] LocalBusiness schema on pages with Lake Days business info
- [ ] Place schema when a specific neighborhood or location is featured

## Part 2: AI Search Optimization (Generative Engine Optimization / GEO)

Google AI Overviews, ChatGPT, Perplexity, and other AI tools pull content that is:

### Structurally Readable
- [ ] Headers match how people naturally ask questions
  - Good: "Best Things to Do at Lake Cumberland With Kids"
  - Bad: "Our Top Picks"
- [ ] Each section answers its own question fully and directly
- [ ] First sentence under each H2/H3 answers the section question directly
- [ ] FAQ answers are self-contained (40-80 words, complete without context)
- [ ] No vague non-answers ("it depends," "results vary") — AI skips these

### Authoritative and Local
- [ ] Real data, stats, or numbers included (even approximate)
- [ ] Real place names, real local businesses, real specifics
- [ ] Mention Lake Cumberland, Jamestown, Russell Springs by name
- [ ] NO invented amenities: no lake views, no hot tubs, no private docks
- [ ] Cite at least one external source (city data, tourism board, MLS, etc.)

### E-E-A-T Signals (Experience, Expertise, Authoritativeness, Trust)
- [ ] Post attributed to a real person (Bob Sophiea, Blaire Sophiea)
- [ ] Author bio at bottom
- [ ] First-person experience statements included ("In our experience working with buyers...")
- [ ] Social proof mentioned (reviews, awards, years in business)
- [ ] No unsupported superlatives ("the best in Kentucky" needs a source)

### Conversational and Complete
- [ ] Written in second person ("you," "your") throughout
- [ ] Questions and answers feel like a real conversation
- [ ] Each FAQ answer could stand alone if pulled by an AI
- [ ] Avoids unnecessary hedging language that weakens answers

### Freshness Signals
- [ ] Include a publish date and "last updated" date
- [ ] Reference current market conditions or current year when relevant
- [ ] Seasonal posts should have clear seasonal context

## Quick Reference: What AI Pulls vs. What It Skips

| AI Pulls | AI Skips |
|----------|----------|
| Direct, complete answers | Vague, hedged answers |
| Headers that match search queries | Generic headers ("Overview," "Summary") |
| Bullet lists with specifics | Long unbroken paragraphs |
| FAQ sections | Content with no question-answer structure |
| Real numbers and data | Unsupported claims |
| Named experts and credentials | Anonymous or generic authorship |
| Local specifics (city, neighborhood) | Generic geographic references |
| Current year/date references | Undated or clearly stale content |
